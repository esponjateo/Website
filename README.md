# Portfolio Website - Intro to Web Development

A personal developer portfolio website inspired by the retro Undertale and Deltarune aesthetics.

## Features
- **Authentic Retro Theme**: Determination TrueType font (`determination.ttf`), pixelated rendering, and Undertale-style dialogue boxes with animated Ralsei GIFs.
- **Responsive Flexbox Architecture**: Centered layout on desktop with side navigation and fluid stacking on mobile/tablet viewports.
- **Projects Showcase**: High-resolution project previews with pixel-art caption headers for web, database, and software projects.
- **Event Production & Media**: Multimedia highlights with direct integration to Google Drive galleries, Google Docs reflection papers, and YouTube video embeds.

## Page Structure
- **Home (`index.html`)**: Developer introduction with interactive Undertale dialogue sequence and profile showcase.
- **Works (`Works.html`)**: Web development and SQL programming projects portfolio.
- **Other Projects (`Commission.html`)**: External collaborations, science films, and technical reels.
- **Event Production (`EventProduction.html`)**: Marketing, playbills, weekly documentation logs, and reflections.
- **Video Editing (`VideoEditing.html`)**: Responsive embedded video demonstration.
